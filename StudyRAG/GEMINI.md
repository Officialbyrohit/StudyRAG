# Strict User-Requested Scope Rule

## 1. Absolute Scope Adherence
- **ONLY modify what the user explicitly asks for**: Change or touch only the exact files, sections, components, and lines of code explicitly stated by the user.
- **ZERO unsolicited changes**: Never modify, delete, refactor, reorganize, or "clean up" even a single line of code in any other part of the project unless the user specifically instructs you to do so.

## 2. No Assumptions or Side-Edits
- If a related adjustment seems necessary or beneficial, do **NOT** make the change automatically. Instead, ask the user first and wait for approval.
- Keep all existing code, styles, classes, and logic completely intact outside the direct target of the request.
